Задание 3 ЕГЭ — упрощённый вариант

Перед тобой база сети магазинов — такая же, как на экзамене, только поменьше: 125 строк вместо тысяч. Глазами тут уже не найдёшь — нужны фильтры.

Твой вариант (назовёт учитель)

Как решать

  1. В таблице «Товар» найди артикул нужного товара.
  2. В таблице «Магазин» найди ID магазинов нужного района.
  3. В «Движении товаров» поставь фильтры: артикул, ID магазина, тип операции.
  4. Внизу посмотри сумму упаковок. Если спрашивают «на сколько увеличилось» — это поступило − продано.

📊База данных

Нажми на кнопку под заголовком столбца — откроется фильтр. Можно отметить несколько значений, как в Excel.

👀Разбор примера

Сколько упаковок батона нарезного продано в магазинах Октябрьского района?

1. Открываем «Товар»: Батон нарезной — артикул 8.
2. Открываем «Магазин»: Октябрьский район — магазины М3 и М4.
3. В «Движении товаров» ставим фильтры: Артикул = 8, ID магазина = М3, М4, Тип операции = Продажа.
4. Смотрим сумму внизу: упаковок. Это и есть ответ!

Шаги сами переключают таблицу и ставят фильтры — смотри на базу выше.
